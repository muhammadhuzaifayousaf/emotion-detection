# Emotion Detection

## Project Description

This project is an AI based web application that analyzes customer feedback and detects emotions from text.

The application uses the Watson NLP Emotion Detection service to identify five emotions:

* Anger
* Disgust
* Fear
* Joy
* Sadness

It also identifies the dominant emotion in the provided text.

## Technologies Used

* Python
* Watson NLP
* Flask
* Requests
* HTML
* CSS
* JavaScript
* unittest
* Pylint

## Features

* Emotion detection from text
* Detection of anger, disgust, fear, joy, and sadness
* Dominant emotion identification
* Flask based web interface
* Error handling for invalid input
* Unit testing
* Static code analysis
